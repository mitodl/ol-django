### Changed

- Raised `cybersource-rest-client-python` to `>=0.0.79,<0.0.80`. SDK releases up to 0.0.63 import `pkg_resources` unconditionally while declaring an unbounded `setuptools` requirement, so an application that resolved setuptools 82 or newer failed to import `mitol.payment_gateway.api`. 0.0.79 declares `setuptools<=81.0.0`, which keeps `pkg_resources` available. The library source does not reference the model classes the SDK renamed between these releases.
